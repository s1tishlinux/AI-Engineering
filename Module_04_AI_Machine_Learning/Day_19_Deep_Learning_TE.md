## 🎯 ఈ సెషన్ లక్ష్యాలు (Learning Objectives)
ఈ క్లాస్ పూర్తయ్యేసరికి మీరు క్రింది అంశాలను చాలా స్పష్టంగా అర్థం చేసుకుంటారు:
1. మానవ మెదడు ప్రేరణ: బయలాజికల్ న్యూరాన్ నుండి **ఆర్టిఫిషియల్ పర్‌సెప్ట్రాన్ (Perceptron)** వరకు.
2. నెట్‌వర్క్ నిర్మాణం: ఇన్‌పుట్ లేయర్, హిడెన్ లేయర్స్, అవుట్‌పుట్ లేయర్, వెయిట్స్ ($W$) & బయాస్ ($b$).
3. నాన్-లీనియారిటీ ఎందుకు అవసరం?: **యాక్టివేషన్ ఫంక్షన్స్** (ReLU, Sigmoid, Softmax).
4. న్యూరల్ నెట్‌వర్క్ ఎలా నేర్చుకుంటుంది?: **ఫార్వర్డ్ పాస్**, **లాస్ ఫంక్షన్**, **బ్యాక్‌ప్రాపగేషన్** & **గ్రేడియంట్ డిసెంట్**.
5. నేటి AI కి వెన్నెముక: **PyTorch** పరిచయం (Tensors, Autograd, `nn.Module`).

## 1. పాత ML కంటే డీప్ లెర్నింగ్ ఎందుకు ఇంత పవర్‌ఫుల్? (The "Why")

సాధారణ మెషిన్ లెర్నింగ్ (Days 16–18) లో మనుషులే స్వయంగా ఫీచర్లను లెక్కించాలి (**Manual Feature Engineering**):
- ఫోటోలో పిల్లిని గుర్తించడానికి మనుషులే రంగులు, అంచులు (Edges) లెక్కించే కోడ్ రాయాలి. కాంతి మారితే ఆ కోడ్ పనిచేయదు!

కానీ **డీప్ లెర్నింగ్ (Deep Learning)** డేటా నుండి ఫీచర్లను స్వయంగా నేర్చుకుంటుంది:
- 1వ లేయర్: చిన్న గీతలను, అంచులను గుర్తిస్తుంది.
- 2వ లేయర్: ఆ గీతలను కలిపి ముక్కు, చెవులు, మీసాలను తయారు చేస్తుంది.
- 3వ లేయర్: ముఖ భాగాలు కలిపి అది పిల్లి అని 100% ఖచ్చితత్వంతో గుర్తిస్తుంది!

## 2. ఆర్టిఫిషియల్ న్యూరాన్ (Perceptron) నిర్మాణం

ఒక ఆర్టిఫిషియల్ న్యూరాన్ అనేక ఇన్‌పుట్లను ($X$) తీసుకుంటుంది, వాటికి ప్రాధాన్యతను బట్టి వెయిట్స్ ($W$) తో గుణిస్తుంది, బయాస్ ($b$) కలిపి, యాక్టివేషన్ ఫంక్షన్ ద్వారా ఫలితాన్ని ఇస్తుంది:

$$z = \sum (X_i \cdot W_i) + b = W^T X + b$$
$$\text{Output} = f(z)$$

```
ఇన్‌పుట్స్ (X)       వెయిట్స్ (W)        కూడిక & బయాస్          యాక్టివేషన్ (f)      ఫలితం (y)
  X1 ─────────────► W1 ────────┐
                               │
  X2 ─────────────► W2 ────────┼───► [ z = Σ(X·W) + b ] ───► [ f(z) = ReLU ] ────► ప్రిడిక్షన్
                               │
  X3 ─────────────► W3 ────────┘
```

## 3. యాక్టివేషన్ ఫంక్షన్స్ ఎందుకు తప్పనిసరి? (Activation Functions)

ఒకవేళ యాక్టివేషన్ ఫంక్షన్ లేకపోతే, మీరు 100 లేయర్ల న్యూరల్ నెట్‌వర్క్ కట్టినా అది కేవలం ఒక సాధారణ లీనియర్ రిగ్రెషన్‌తో సమానం అయిపోతుంది!
యాక్టివేషన్ ఫంక్షన్లు **నాన్-లీనియారిటీ (వంకరలు, మలుపులు)** ను నెట్‌వర్క్‌కి అందిస్తాయి. దీనివల్ల ప్రపంచంలోని అత్యంత క్లిష్టమైన సమస్యలను కూడా నెట్‌వర్క్ నేర్చుకోగలదు.

| యాక్టివేషన్ | ఫార్ములా | విలువలు | ఎప్పుడు వాడాలి? |
| :--- | :--- | :--- | :--- |
| **ReLU** | $f(z) = \max(0, z)$ | $[0, \infty)$ | **లోపల ఉండే అన్ని హిడెన్ లేయర్లకు ఇదే మొదటి ఎంపిక!** |
| **Sigmoid** | $\sigma(z) = \frac{1}{1 + e^{-z}}$ | $(0, 1)$ | **బైనరీ క్లాసిఫికేషన్ (అవునా/కాదా)** చివరి లేయర్‌లో |
| **Softmax** | $\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum e^{z_j}}$ | $(0, 1)$ (మొత్తం కలిపితే 1.0) | **మల్టీ-క్లాస్ క్లాసిఫికేషన్ (పిల్లి/కుక్క/గుర్రం)** చివరి లేయర్‌లో |

## 4. న్యూరల్ నెట్‌వర్క్ ఎలా నేర్చుకుంటుంది? (The 4-Step Loop)

నెట్‌వర్క్ లెర్నింగ్ అనేది నిరంతరం తిరిగే 4 స్టెప్పుల చక్రం:

1. **ఫార్వర్డ్ పాస్ (Forward Pass):** ఇన్‌పుట్ ఇచ్చి నెట్‌వర్క్ అంచనా సమాధానాన్ని ($y_{\text{pred}}$) లెక్కించడం.
2. **లాస్ కంప్యూటేషన్ (Compute Loss):** మోడల్ ఎంత ఘోరమైన తప్పు చేసిందో కొలవడం (Error).
3. **బ్యాక్‌ప్రాపగేషన్ (Backpropagation - Chain Rule):** వచ్చిన తప్పుకు ఏయే వెయిట్స్ ఎంతవరకు కారణమో వెనుక నుండి లెక్కించడం ($\frac{\partial \text{Loss}}{\partial W}$).
4. **వెయిట్స్ అప్‌డేట్ (Gradient Descent):** తప్పును తగ్గించడానికి లెర్నింగ్ రేట్ ($\alpha$) తో వెయిట్స్‌ను సవరించడం:
   $$W_{\text{new}} = W_{\text{old}} - \alpha \cdot \frac{\partial \text{Loss}}{\partial W}$$

## 5. పైథాన్‌లో PyTorch: ప్రాక్టికల్ కోడ్

ప్రపంచవ్యాప్తంగా OpenAI, Meta, Google లు తమ ఆధునిక AI రీసెర్చ్ కోసం **PyTorch** నే ఉపయోగిస్తాయి.

```python
import torch
import torch.nn as nn
import torch.optim as optim

# ఒక సింపుల్ న్యూరల్ నెట్‌వర్క్ క్లాస్ తయారు చేయడం
class SimpleClassifier(nn.Module):
    def __init__(self, input_dim: int, hidden_dim: int, output_dim: int):
        super().__init__()
        self.fc1 = nn.Linear(input_dim, hidden_dim)  # మొదటి లేయర్
        self.relu = nn.ReLU()                        # యాక్టివేషన్
        self.fc2 = nn.Linear(hidden_dim, output_dim) # రెండవ లేయర్

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        out = self.fc1(x)
        out = self.relu(out)
        out = self.fc2(out)
        return out

# చిన్న డమ్మీ డేటా (4 శాంపిల్స్, 3 ఫీచర్స్)
X_train = torch.tensor([[1.0, 2.0, 0.5], [2.0, 1.0, 0.8], [0.5, 0.2, 0.1], [3.0, 2.5, 1.2]])
y_train = torch.tensor([1, 1, 0, 1])

# మోడల్, లాస్ మరియు ఆప్టిమైజర్ సెటప్
model = SimpleClassifier(input_dim=3, hidden_dim=8, output_dim=2)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.01)

# ట్రైనింగ్ లూప్ (50 ఎపోక్స్)
print("న్యూరల్ నెట్‌వర్క్ ట్రైనింగ్ ప్రారంభమైంది...")
for epoch in range(1, 51):
    optimizer.zero_grad()                  # 1. పాత గ్రేడియంట్లను క్లియర్ చేయడం
    predictions = model(X_train)           # 2. ఫార్వర్డ్ పాస్
    loss = criterion(predictions, y_train) # 3. లాస్ లెక్కించడం
    loss.backward()                        # 4. బ్యాక్‌ప్రాపగేషన్
    optimizer.step()                       # 5. వెయిట్స్ మార్చడం

    if epoch % 10 == 0:
        print(f"ఎపోక్ [{epoch:02d}/50] - ఎర్రర్ (Loss): {loss.item():.4f}")

# కొత్త శాంపిల్‌పై ఇన్ఫరెన్స్
sample = torch.tensor([[0.2, 0.1, 0.05]])
with torch.no_grad():
    raw_logits = model(sample)
    predicted_class = torch.argmax(raw_logits, dim=1).item()
    print(f"\nకొత్త శాంపిల్ ఫలితం: క్లాస్ {predicted_class}")
```

## 6. ఫ్రెషర్స్ చేసే సాధారణ తప్పులు (Common Pitfalls)

1. **`optimizer.zero_grad()` మర్చిపోవడం:**
   - PyTorch లో గ్రేడియంట్స్ ఆటోమేటిక్‌గా కూడుకుంటూ పోతాయి. లూప్ మొదట్లో `zero_grad()` కొట్టకపోతే పాత ఎపోక్ ఎర్రర్ కొత్తదానికి కలిసిపోయి మోడల్ క్రాష్ అవుతుంది!
2. **లెర్నింగ్ రేట్ ($\alpha$) చాలా ఎక్కువగా పెట్టడం:**
   - లెర్నింగ్ రేట్ 1.0 లాంటి పెద్దది పెడితే లాస్ తగ్గకపోగా అనంతానికి వెళ్లి `NaN` (Not a Number) వస్తుంది.
3. **ఇన్ఫరెన్స్ చేసేటప్పుడు `torch.no_grad()` వాడకపోవడం:**
   - కేవలం ప్రిడిక్షన్ చేసేటప్పుడు `torch.no_grad()` పెట్టకపోతే కంప్యూటర్ బ్యాక్‌ప్రాపగేషన్ గ్రాఫ్‌ను మెమొరీలో నిల్వ చేస్తూ GPU ని జామ్ చేసేస్తుంది.

## 7. ప్రాక్టీస్ ల్యాబ్ (Daily Hands-On Lab)

### 🧪 టాస్క్: కస్టమర్ రివ్యూ సెంటిమెంట్ అనలైజర్ నెట్‌వర్క్
**సన్నివేశం:** కస్టమర్ రాసిన రివ్యూల ఆధారంగా పాజిటివ్ (1) లేదా నెగటివ్ (0) అని గుర్తించే ఒక బైనరీ క్లాసిఫైయర్ న్యూరల్ నెట్‌వర్క్‌ను PyTorch లో నిర్మించండి.

```python
# =========================================================
# Day 19 Lab: PyTorch సెంటిమెంట్ క్లాసిఫికేషన్ నెట్‌వర్క్
# =========================================================
import torch
import torch.nn as nn
import torch.optim as optim

# శాంపిల్ రివ్యూ ఫీచర్లు: [పాజిటివ్ పదాలు, నెగటివ్ పదాలు, టెక్స్ట్ పొడవు, ఎక్స్‌క్లమేషన్ మార్కులు]
X_reviews = torch.tensor([
    [0.9, 0.1, 0.5, 0.8],  # "చాలా బాగుంది! సూపర్ సర్వీస్!" -> పాజిటివ్ (1)
    [0.8, 0.2, 0.3, 0.6],  # "మంచి ప్రోడక్ట్, వేగంగా డెలివరీ అయింది" -> పాజిటివ్ (1)
    [0.1, 0.9, 0.8, 0.9],  # "చెత్త సర్వీస్, డెలివరీలో పగిలిపోయింది!" -> నెగటివ్ (0)
    [0.2, 0.8, 0.4, 0.3]   # "డబ్బులు దండగ, క్వాలిటీ అస్సలు బాలేదు" -> నెగటివ్ (0)
], dtype=torch.float32)

y_sentiment = torch.tensor([[1.0], [1.0], [0.0], [0.0]], dtype=torch.float32)

class SentimentNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.network = nn.Sequential(
            nn.Linear(4, 8),
            nn.ReLU(),
            nn.Linear(8, 1),
            nn.Sigmoid()  # 0.0 నుండి 1.0 మధ్య సంభావ్యతను ఇస్తుంది
        )

    def forward(self, x):
        return self.network(x)

net = SentimentNetwork()
criterion = nn.BCELoss()  # Binary Cross Entropy
optimizer = optim.SGD(net.parameters(), lr=0.1)

# ట్రైనింగ్
for epoch in range(1, 101):
    optimizer.zero_grad()
    outputs = net(X_reviews)
    loss = criterion(outputs, y_sentiment)
    loss.backward()
    optimizer.step()

# కొత్త రివ్యూపై పరీక్ష:
new_review = torch.tensor([[0.85, 0.15, 0.4, 0.7]])
with torch.no_grad():
    prob = net(new_review).item()
    print("="*45)
    print("రివ్యూ సెంటిమెంట్ విశ్లేషణ")
    print("="*45)
    print(f"పాజిటివ్ సెంటిమెంట్ అవకాశం: {prob * 100:.2f}%")
    print(f"చివరి తీర్పు : {'పాజిటివ్ రివ్యూ (POSITIVE)' if prob >= 0.5 else 'నెగటివ్ రివ్యూ (NEGATIVE)'}")
    print("="*45)
```

## 8. ఇంటర్వ్యూలలో అడిగే ప్రశ్నలు (Interview Questions & Answers)

1. **ప్రశ్న: డీప్ న్యూరల్ నెట్‌వర్క్‌ల హిడెన్ లేయర్లలో Sigmoid కంటే ReLU ఎందుకు బెటర్?**
   - **సమాధానం:** Sigmoid ఫంక్షన్ ఎక్కువ పాజిటివ్ లేదా ఎక్కువ నెగటివ్ విలువల వద్ద ఫ్లాట్ అయిపోతుంది. దీనివల్ల బ్యాక్‌ప్రాపగేషన్ చేసేటప్పుడు డెరివేటివ్ సున్నాకి చేరుకుని ప్రారంభ లేయర్లకు ఎర్రర్ సమాచారం అందదు (**Vanishing Gradient Problem**). కానీ ReLU ఫంక్షన్‌లో పాజిటివ్ విలువల వద్ద డెరివేటివ్ ఎల్లప్పుడూ 1 గా ఉంటుంది; కాబట్టి నెట్‌వర్క్ ఎన్ని లేయర్లు ఉన్నా చాలా వేగంగా నేర్చుకుంటుంది.
2. **ప్రశ్న: Batch GD, SGD మరియు Mini-Batch Gradient Descent మధ్య తేడా ఏమిటి?**
   - **సమాధానం:** **Batch GD** మొత్తం డేటాపై లాస్ లెక్కించాకే ఒకసారి వెయిట్స్ అప్‌డేట్ చేస్తుంది (స్లో). **SGD** ప్రతి ఒక్క శాంపిల్ తర్వాత వెంటనే వెయిట్స్ అప్‌డేట్ చేస్తుంది (వేగంగా ఉంటుంది కానీ ఎక్కువ ఊగిసలాడుతుంది). **Mini-Batch GD** అనేది 32 లేదా 64 శాంపిల్స్ చొప్పున బ్యాచ్‌లుగా వెయిట్స్ అప్‌డేట్ చేస్తుంది (ఇదే ఆధునిక పరిశ్రమ స్టాండర్డ్).
3. **ప్రశ్న: Softmax ఫంక్షన్ ముఖ్య ఉద్దేశం ఏమిటి?**
   - **సమాధానం:** నెట్‌వర్క్ చివరి లేయర్ ఇచ్చే రా నంబర్లను (Logits) క్రమబద్ధీకరించి, అన్ని క్లాసుల సంభావ్యతల మొత్తం ఖచ్చితంగా 1.0 (100%) అయ్యేలా ఒక ప్రాబబిలిటీ డిస్ట్రిబ్యూషన్‌గా మార్చడమే Softmax పని.
