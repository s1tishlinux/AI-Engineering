## 1. సాధారణ ప్రోగ్రామింగ్ నుండి ML కి ఎలా మారాం? (The "Why")

గత 15 రోజుల్లో మనం చేసిన సంప్రదాయ ప్రోగ్రామింగ్:
$$\text{మనం రాసిన రూల్స్ (Code)} + \text{ఇన్‌పుట్ డేటా} \longrightarrow \text{ఫలితం (Output)}$$
*ఉదాహరణ: ఒక ఈమెయిల్ స్పామా కాదా అని తెలుసుకోవడానికి మనమే 50 `if-else` కండిషన్లు రాశాం.*

కానీ మెషిన్ లెర్నింగ్ (ML) లో:
$$\text{పాత డేటా (Past Data)} + \text{సమాధానాలు (Labels)} \longrightarrow \text{రూల్స్ (ట్రైన్ అయిన మోడల్!)}$$
మనుషులు వేలాది కండిషన్లు రాయాల్సిన పనిలేకుండా, గతంలో జరిగిన వేలాది ఉదాహరణల నుండి **కంప్యూటరే స్వయంగా ఆ ఫార్ములాను (ప్యాటర్న్‌ను) కనిపెడుతుంది!**

## 4. ప్రాథమిక లైబ్రరీలు: NumPy & Pandas

### A. NumPy: సూపర్ ఫాస్ట్ మ్యాథమెటికల్ కంప్యూటింగ్
సాధారణ పైథాన్ లిస్ట్‌లు స్లోగా ఉంటాయి. NumPy అనేది మెమొరీలో డేటాను నేరుగా C లాంగ్వేజ్ వేగంతో అమరుస్తుంది; దీనివల్ల లెక్కలు **100 రెట్లు వేగంగా** జరుగుతాయి.

```python
import numpy as np

# అరే (Array) క్రియేట్ చేయడం
arr = np.array([10, 20, 30, 40, 50])

# వెక్టరైజేషన్: ఎలాంటి లూప్స్ లేకుండా ఒకేసారి అన్నింటినీ గుణించడం!
scaled = arr * 2.5
print("వెక్టరైజ్డ్ గుణకారం:", scaled)

# గణిత కొలతలు
print("సగటు (Mean):", np.mean(arr))
print("ప్రామాణిక విచలనం (Std):", np.std(arr))

# 2D మ్యాట్రిక్స్ (టెన్సార్ బేసిక్స్)
matrix = np.array([[1, 2], [3, 4]])
print("మ్యాట్రిక్స్ షేప్:", matrix.shape)
print("మ్యాట్రిక్స్ ట్రాన్స్‌పోజ్:\n", matrix.T)
```

### B. Pandas: డేటా సైన్స్ యొక్క ఎక్సెల్ షీట్
టేబుల్ రూపంలో ఉండే డేటాను విశ్లేషించడానికి `DataFrame` అత్యంత శక్తివంతమైన సాధనం.

```python
import pandas as pd

raw_data = {
    "Employee": ["ఆరవ్", "పూజ", "విక్రమ్", "స్నేహ", "కరణ్"],
    "Department": ["AI", "Cloud", "AI", "DevOps", "AI"],
    "Experience_Yrs": [2.5, 5.0, 1.0, 8.0, None],  # డేటా మిస్ అయింది!
    "Salary_INR": [850000, 1400000, 600000, 1950000, 750000]
}

df = pd.DataFrame(raw_data)

# 1. సమ్మరీ చూడటం
print("డేటా పరిమాణం:", df.shape)
print("\nగణాంకాలు:\n", df.describe())

# 2. మిస్సింగ్ డేటాను పూరించడం (Imputation with Median)
median_exp = df["Experience_Yrs"].median()
df["Experience_Yrs"] = df["Experience_Yrs"].fillna(median_exp)

# 3. ఫిల్టరింగ్: ఎక్కువ జీతం ఉన్న AI ఇంజనీర్లు
ai_high_earners = df[(df["Department"] == "AI") & (df["Salary_INR"] > 700000)]
print("\nAI స్పెషలిస్టులు:\n", ai_high_earners[["Employee", "Salary_INR"]])

# 4. గ్రూపింగ్: ఏ డిపార్ట్‌మెంట్‌కి సగటున ఎంత జీతం ఇస్తున్నాం?
avg_dept_salary = df.groupby("Department")["Salary_INR"].mean()
print("\nవిభాగాల వారీగా సగటు జీతం:\n", avg_dept_salary)
```

## 5. ఫ్రెషర్స్ చేసే సాధారణ తప్పులు (Common Pitfalls)

1. **NumPy లో లూప్‌లు రాయడం:** `for` లూప్ రాస్తే NumPy వాడటంలో అర్థమే లేదు. ఎల్లప్పుడూ వెక్టరైజ్డ్ ఆపరేషన్స్ మాత్రమే వాడాలి.
2. **Pandas లో చైన్డ్ అసైన్‌మెంట్ (`SettingWithCopyWarning`):** 
   - `df[df['A'] > 5]['B'] = 10` అని రాస్తే వార్నింగ్ వస్తుంది. ఎల్లప్పుడూ `df.loc[condition, 'column'] = value` అని రాయాలి.
3. **డేటా లీకేజ్ (Data Leakage):**
   - డేటాను Train మరియు Test గా విభజించక ముందే మొత్తం డేటా సగటును లెక్కిస్తే భవిష్యత్తు డేటా మోడల్‌కి తెలిసిపోయి నిజమైన పరీక్షలో ఫెయిల్ అవుతుంది.

## 6. ప్రాక్టీస్ ల్యాబ్ (Daily Hands-On Lab)

### 🧪 టాస్క్: టెలికాం కస్టమర్ల డేటా క్లీనింగ్ & చర్న్ అనాలిసిస్
**సన్నివేశం:** ఒక టెలికాం కంపెనీలో కస్టమర్లు సబ్‌స్క్రిప్షన్ రద్దు చేసుకుని వెళ్లిపోతున్నారు (Churn). తప్పుడు రోస్ సరిదిద్ది, మిస్సింగ్ డేటా ఫిల్ చేసి, ఏ కాంట్రాక్ట్ ఉన్నవారు ఎక్కువగా వెళ్లిపోతున్నారో విశ్లేషించండి.

```python
# =========================================================
# Day 16 Lab: కస్టమర్ డేటా క్లీనింగ్ పైప్‌లైన్
# =========================================================
import pandas as pd
import numpy as np

dirty_telecom_data = {
    "customer_id": [101, 102, 103, 104, 105, 106],
    "monthly_charges": [450.0, 990.5, None, 1250.0, 350.0, 800.0],
    "contract_type": ["Month-to-Month", "Two-Year", "Month-to-Month", "One-Year", None, "Month-to-Month"],
    "tenure_months": [2, 36, 12, 24, 1, 8],
    "churned": [1, 0, 1, 0, 1, 0]  # 1 = వెళ్ళిపోయారు, 0 = కంపెనీలోనే ఉన్నారు
}

df_cust = pd.DataFrame(dirty_telecom_data)
print("--- ముడి డేటా (RAW DATA) ---")
print(df_cust)

# 1. నెలవారీ ఛార్జీల మిస్సింగ్ వాల్యూలను సగటుతో పూరించడం
mean_charge = df_cust["monthly_charges"].mean()
df_cust["monthly_charges"] = df_cust["monthly_charges"].fillna(np.round(mean_charge, 2))

# 2. కాంట్రాక్ట్ టైప్ మిస్సింగ్ వాల్యూని ఎక్కువమంది వాడే రకంతో (Mode) పూరించడం
mode_contract = df_cust["contract_type"].mode()[0]
df_cust["contract_type"] = df_cust["contract_type"].fillna(mode_contract)

# 3. కొత్త ఫీచర్ క్రియేట్ చేయడం: మొత్తం లైఫ్‌టైమ్ వాల్యూ (Tenure * Monthly Charge)
df_cust["estimated_lifetime_val"] = df_cust["tenure_months"] * df_cust["monthly_charges"]

# 4. కాంట్రాక్ట్ రకం వారీగా కస్టమర్లు వెళ్ళిపోయే శాతం (Churn Rate)
churn_rate = df_cust.groupby("contract_type")["churned"].mean() * 100

print("\n--- క్లీన్ చేసిన పూర్తి డేటా ---")
print(df_cust[["customer_id", "monthly_charges", "contract_type", "estimated_lifetime_val", "churned"]])

print("\n--- కాంట్రాక్ట్ వారీగా చర్న్ రేట్ (%) ---")
for contract, rate in churn_rate.items():
    print(f"  • {contract:16}: {rate:.1f}% కస్టమర్లు వెళ్లిపోయారు")
```

## 7. ఇంటర్వ్యూలలో అడిగే ప్రశ్నలు (Interview Questions & Answers)

1. **ప్రశ్న: సూపర్‌వైజ్డ్ మరియు అన్‌సూపర్‌వైజ్డ్ లెర్నింగ్ మధ్య ప్రధాన తేడా ఏమిటి?**
   - **సమాధానం:** సూపర్‌వైజ్డ్ లెర్నింగ్‌లో మోడల్‌కు ఇన్‌పుట్‌లతో పాటు సరైన సమాధానాలు (లేబుల్స్ - $y$) కూడా ఇస్తాం; మోడల్ ఆ రెండింటి మధ్య సంబంధాన్ని నేర్చుకుంటుంది. అన్‌సూపర్‌వైజ్డ్ లెర్నింగ్‌లో ఎలాంటి సమాధానాలు ఇవ్వము; డేటాలోని దాగి ఉన్న సమూహాలను (Clusters) మరియు పోలికలను మోడల్ స్వయంగా గుర్తిస్తుంది.
2. **ప్రశ్న: సాధారణ పైథాన్ లిస్ట్ కంటే NumPy అరే ఎందుకు వేగంగా ఉంటుంది?**
   - **సమాధానం:** NumPy అరేలు హోమోజీనియస్ (అన్ని ఎలిమెంట్లు ఒకే రకమైన డేటా టైప్ కలిగి ఉంటాయి) మరియు మెమొరీలో పక్కపక్కనే నిరంతరాయంగా (Contiguous blocks) నిల్వ చేయబడతాయి. దీనివల్ల CPU లోని వెక్టర్ ప్రాసెసింగ్ (SIMD) సహాయంతో ఒకే సమయంలో వేలాది గణనలు పూర్తి చేయగలవు. పైథాన్ లిస్ట్‌లు కేవలం వేర్వేరు మెమొరీ పాయింటర్లను మాత్రమే స్టోర్ చేయడం వల్ల స్లోగా ఉంటాయి.
3. **ప్రశ్న: Pandas Series మరియు DataFrame మధ్య తేడా ఏమిటి?**
   - **సమాధానం:** `Series` అనేది ఇండెక్స్‌తో కూడిన 1-డైమెన్షనల్ డేటా స్ట్రక్చర్ (టేబుల్‌లోని ఒకే ఒక్క కాలమ్ లాంటిది). `DataFrame` అనేది అడ్డు వరుసలు (Rows) మరియు నిలువు వరుసలతో (Columns) కూడిన 2-డైమెన్షనల్ టేబుల్ (అనేక సిరీస్‌ల కలయిక).
