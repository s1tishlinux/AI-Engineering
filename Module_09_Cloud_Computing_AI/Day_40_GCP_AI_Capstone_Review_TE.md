## 4. క్లౌడ్ ఎంపిక నిర్ణయ మాతృక (AWS vs Azure vs GCP)

| :--- | :--- | :--- |
| **Google Cloud (GCP)** | - **అత్యుత్తమ మల్టీమోడల్ & లాంగ్ కాంటెక్స్ట్** (Gemini 20 లక్షల టోకెన్లు).<br>- **BigQuery ML** (SQL తోనే AI మోడల్స్).<br>- **కంటైనర్ లీడర్‌షిప్** (Kubernetes, Cloud Run కనిపెట్టింది గూగులే). | డేటా ఎక్కువగా ఉన్న కంపెనీలు, వీడియో/ఆడియో ఎనలిటిక్స్, వేగంగా మూవ్ అయ్యే ఆధునిక స్టార్టప్‌లు. |
| **Microsoft Azure** | - **OpenAI ప్రత్యక్ష భాగస్వామ్యం** (GPT-4o ప్రైవేట్ యాక్సెస్).<br>- **Active Directory (Entra ID) అనుసంధానం**.<br>- **MS Office / Teams ఎకోసిస్టమ్**. | సంప్రదాయ పెద్ద కంపెనీలు, బ్యాంకులు, హెల్త్‌కేర్, మైక్రోసాఫ్ట్ సాఫ్ట్‌వేర్ వాడే ఎంటర్‌ప్రైజెస్. |
| **AWS** | - **Bedrock లో అత్యధిక మోడల్స్** (Claude, Llama, Mistral అన్నీ ఒకే చోట).<br>- **SageMaker పరిపక్వత** (కస్టమ్ క్లస్టర్ ట్రైనింగ్).<br>- **ప్రపంచంలోనే అతిపెద్ద క్లౌడ్ మార్కెట్ షేర్**. | ఏ ఒక్క కంపెనీ మోడల్ పై ఆధారపడకూడదు అనుకునే సంస్థలు, అతిపెద్ద కస్టమ్ క్లౌడ్ నెట్‌వర్క్ కావాల్సిన వారు. |

## 5. కోడింగ్ వాక్‌త్రూ: Python లో Google GenAI SDK తో Gemini ని కాల్ చేయడం

అధికారిక మరియు సరికొత్త `google-genai` SDK ఉపయోగించి Gemini 2.5 Flash ని ఎలా కాల్ చేయాలో చూద్దాం:

```python
# gcp_gemini_demo.py
import os
from google import genai
from google.genai import types

def run_gemini():
    # 1. అధికారిక గూగుల్ క్లయింట్ ప్రారంభం
    # GEMINI_API_KEY లేదా GCP Application Default Credentials (ADC) ని ఆటోమేటిక్ గా తీసుకుంటుంది
    client = genai.Client()

    prompt = """
    నువ్వు ఒక సీనియర్ గూగుల్ క్లౌడ్ ఆర్కిటెక్ట్‌వి.
    FastAPI మరియు Docker ఉపయోగించి నిర్మించిన AI మైక్రోసర్వీస్ ని
    Google Cloud Run లో ఎందుకు డిప్లాయ్ చేయాలో 3 ప్రధాన కారణాలు తెలుగులో బుల్లెట్ పాయింట్లలో వివరించు.
    """

    print("🚀 Google Cloud లో Gemini 2.5 Flash కి రిక్వెస్ట్ వెళ్తోంది...")

    try:
        # 2. మోడల్ ని ఇన్వోక్ చేయడం
        response = client.models.generate_content(
            model="gemini-2.5-flash",
            contents=prompt,
            config=types.GenerateContentConfig(
                temperature=0.2,
                max_output_tokens=400,
                system_instruction="నువ్వు తెలుగు సాంకేతిక నిపుణుడివి."
            )
        )

        print("\n--- 📩 Gemini ఇచ్చిన సమాధానం ---")
        print(response.text)

        # 3. టోకెన్ వివరాల పరిశీలన
        if response.usage_metadata:
            print("\n--- 📊 టోకెన్ మెట్రిక్స్ ---")
            print(f"ఇన్‌పుట్ టోకెన్లు : {response.usage_metadata.prompt_token_count}")
            print(f"అవుట్‌పుట్ టోకెన్లు: {response.usage_metadata.candidates_token_count}")
            print(f"మొత్తం టోకెన్లు  : {response.usage_metadata.total_token_count}")

        return response.text

    except Exception as err:
        print(f"❌ Gemini కాల్ లో లోపం: {str(err)}")
        return None

if __name__ == "__main__":
    run_gemini()
```

## 7. ప్రాక్టికల్ క్యాప్‌స్టోన్ ల్యాబ్: ఎండ్‌-టు-ఎండ్‌ AI మైక్రోసర్వీస్

### లక్ష్యం:
గత 40 రోజుల్లో నేర్చుకున్న అన్ని విభాగాలను కలిపి ఒక సంపూర్ణ ప్రొడక్షన్-గ్రేడ్ API ని రాయడం:
1. **Pydantic Model** తో ఇన్పుట్ డేటా వాలిడేషన్.
2. **FastAPI** తో హై-స్పీడ్ REST ఎండ్‌పాయింట్.
3. **సెక్యూరిటీ గార్డ్‌రెయిల్** తో SQL Injection లేదా హానికర ప్రాంప్ట్స్ ని అడ్డుకోవడం.
4. **టెలిమెట్రీ లాగింగ్** తో లేటెన్సీ (Latency) ని లెక్కించడం.

```python
# capstone_app.py
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field
import time

app = FastAPI(
    title="తెలంగాణ AI అసిస్టెంట్ API",
    description="40 రోజుల కోర్సు ముగింపు క్యాప్‌స్టోన్ ప్రాజెక్ట్",
    version="1.0.0"
)

class ChatRequest(BaseModel):
    query: str = Field(..., min_length=2, example="క్లౌడ్ మరియు MLOps ఎందుకు అవసరం?")
    user_id: str = Field(..., example="emp_502")

class ChatResponse(BaseModel):
    answer: str
    execution_time_ms: float
    model_name: str

@app.get("/health")
def health_status():
    return {"status": "ONLINE", "service": "GCP Cloud Run Microservice", "version": "1.0.0"}

@app.post("/v1/chat", response_model=ChatResponse)
def handle_chat(req: ChatRequest):
    start_time = time.perf_counter()

    # సెక్యూరిటీ గార్డ్‌రెయిల్ చెక్
    forbidden = ["DROP TABLE", "DELETE FROM", "SYSTEM OVERRIDE"]
    if any(f in req.query.upper() for f in forbidden):
        raise HTTPException(status_code=400, detail="భద్రతా హెచ్చరిక: నిషేధించబడిన కమాండ్ గుర్తించబడింది.")

    # సిమ్యులేటెడ్ AI రెస్పాన్స్
    result_text = (
        f"యూజర్ {req.user_id} అడిగిన ప్రశ్నకు సమాధానం: ఆధునిక సాఫ్ట్‌వేర్ ఇంజనీరింగ్ లో "
        "ఆటోమేటెడ్ CI/CD, డాకర్ కంటైనర్లు మరియు క్లౌడ్ సర్వీసెస్ ద్వారానే మోడల్స్ సమర్థవంతంగా పనిచేస్తాయి."
    )

    elapsed_ms = (time.perf_counter() - start_time) * 1000
    return ChatResponse(
        answer=result_text,
        execution_time_ms=round(elapsed_ms, 2),
        model_name="gemini-2.5-flash-enterprise"
    )
```

## 8. టాప్ 3 ఫైనల్ ఇంటర్వ్యూ ప్రశ్నలు & కెరీర్ గైడెన్స్

### Q1: ప్రొడక్షన్ లో RAG వాడాలా లేక మోడల్ ని Fine-Tune చేయాలా అని ఎలా నిర్ణయిస్తారు?
**సమాధానం:**
- **RAG ఎప్పుడు వాడాలి:** మీ దగ్గర ఉన్న సమాచారం నిరంతరం మారుతున్నప్పుడు (కంపెనీ పిడిఎఫ్ లు, బ్యాంక్ రికార్డులు, కస్టమర్ డేటా), మరియు సమాధానానికి ఖచ్చితమైన ఆధారాలు (Citations) చూపించాల్సి వచ్చినప్పుడు. డాక్యుమెంట్లు మారినప్పుడల్లా వెక్టర్ డేటాబేస్ లో వేస్తే సరిపోతుంది, ఖర్చు చాలా తక్కువ.
- **Fine-Tuning ఎప్పుడు వాడాలి:** మోడల్ యొక్క **ప్రవర్తన, శైలి (Tone), లేదా ప్రత్యేకమైన ఫార్మాట్** (ఉదా: కంపెనీ సొంత ప్రోగ్రామింగ్ భాషలో కోడ్ రాయడం, లేదా డాక్టర్ల కోసం నిర్దిష్ట మెడికల్ పరిభాషలో మాట్లాడటం) నేర్పించాలనుకున్నప్పుడు మాత్రమే ఫైన్-ట్యూనింగ్ చేయాలి.

### Q2: ప్రొడక్షన్-గ్రేడ్ AI ఆర్కిటెక్చర్ లో ఉండాల్సిన 3 ముఖ్యమైన లేయర్స్ ఏమిటి?
**సమాధానం:**
1. **కోర్ లాజిక్ & ఆర్కెస్ట్రేషన్ లేయర్:** FastAPI, LangGraph, Pydantic తో కూడిన ఖచ్చితమైన స్టేట్‌ఫుల్ డేటా ఫ్లో.
2. **MLOps & ఎవాల్యుయేషన్ గార్డ్‌రెయిల్స్:** Docker కంటైనర్లు, GitHub Actions CI/CD, డేటా డ్రిఫ్ట్ మానిటరింగ్ (KS/PSI), మరియు ట్రేసింగ్ (Langfuse/Ragas).
3. **క్లౌడ్ ఇన్ఫ్రాస్ట్రక్చర్ & సెక్యూరిటీ:** IAM రోల్స్ ఆధారిత జీరో-ట్రస్ట్ ఆథెంటికేషన్, సర్వర్‌లెస్ ఆటో-స్కేలింగ్ (Cloud Run/Bedrock), మరియు ప్రైవేట్ వర్చువల్ నెట్‌వర్క్స్ (VPC).

### Q3: నేడు AI ఇంజనీరింగ్ రంగంలోకి అడుగుపెడుతున్న ఫ్రెషర్స్ కి మీ ఇచ్చే ముఖ్యమైన సలహా ఏమిటి?
**సమాధానం:**
కేవలం ChatGPT లో ప్రాంప్ట్‌లు పేస్ట్ చేసే సాధారణ యూజర్‌గా మిగిలిపోకండి. కంపెనీలకు కావాల్సింది మోడల్ వెనుక ఉండే పూర్తి వ్యవస్థను అర్థం చేసుకునే ఇంజనీర్లు:
- పైథాన్ బేసిక్స్, Async ప్రోగ్రామింగ్, మరియు టైప్ సేఫ్టీ లో పట్టు సాధించండి.
- ఎంబెడ్డింగ్స్, వెక్టర్ డేటాబేస్‌ల వెనుక ఉన్న లాజిక్ ను స్పష్టంగా అర్థం చేసుకోండి.
- డాకర్, CI/CD, మరియు క్లౌడ్ డిప్లాయ్‌మెంట్స్ స్వయంగా చేయగలగాలి.
ఈ 40 రోజుల సిలబస్‌ను క్రమం తప్పకుండా సాధన చేసిన ఏ ఫ్రెషర్ అయినా అత్యున్నత స్థాయి క్లౌడ్ AI జాబ్‌ను సులభంగా సాధించగలరు! All the best!
