## 1. నేరుగా SDK వాడకుండా ఫ్రేమ్‌వర్క్స్ ఎందుకు వాడాలి? (The "Why")

చిన్న చిన్న ప్రాజెక్టులకు డైరెక్ట్‌గా గూగుల్ జెమిని లేదా OpenAI SDK కాల్స్ రాయడం బాగానే ఉంటుంది. కానీ పెద్ద కంపెనీ ప్రాజెక్టులలో:
- రేపు జెమిని నుండి OpenAI కి లేదా Claude కి మారాలంటే పాత కోడ్ మొత్తం తిరగరాయాల్సి వస్తుంది.
- 5 రకాల డేటా సోర్సెస్ (PDFs, Confluence, Slack, SQL) నుండి డేటాను తీసుకురావడానికి వందలాది లైన్ల స్క్రాపింగ్ కోడ్ రాయాలి.
- ఒకదాని తర్వాత ఒకటి అనేక పనులు జరగాలంటే (*డాక్యుమెంట్ సారాంశం తీయడం $\rightarrow$ తెలుగులోకి అనువాదం $\rightarrow$ JSON లోకి మార్చడం*) వరుస ఫంక్షన్లతో కోడ్ గజిబిజిగా మారుతుంది.

**LangChain మరియు LlamaIndex ఫ్రేమ్‌వర్కులు ఈ పనులన్నింటినీ లెగో బ్లాకుల్లా సులభంగా అనుసంధానించే రెడీమేడ్ టూల్స్‌ను అందిస్తాయి.**

## 2. లాంగ్‌చైన్ ఎక్స్‌ప్రెషన్ లాంగ్వేజ్ (LCEL - Unix Pipe Magic)

ఆధునిక లాంగ్‌చైన్ (v0.2+) యునిక్స్ పైప్ ఆపరేటర్ `|` స్ఫూర్తితో రూపొందించబడింది:
```bash
cat file.txt | grep "ERROR" | wc -l
```

లాంగ్‌చైన్‌లో భాగాలు పైప్ ద్వారా ఒకదానికొకటి చాలా సులభంగా కనెక్ట్ అవుతాయి:

$$\text{ప్రాంప్ట్ టెంప్లేట్} \;\;|\;\; \text{LLM మోడల్} \;\;|\;\; \text{అవుట్‌పుట్ పార్సర్}$$

```python
# రన్ చేయడానికి: pip install langchain-core langchain-google-genai
import os
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_google_genai import ChatGoogleGenerativeAI

# 1. ప్రాంప్ట్ టెంప్లేట్ (ఇన్‌పుట్ వేరియబుల్స్‌తో)
prompt_template = ChatPromptTemplate.from_messages([
    ("system", "నువ్వు ఒక సీనియర్ పైథాన్ ఆర్కిటెక్ట్‌వి. సూటిగా మరియు వేగంగా వివరించు."),
    ("user", "{concept} అనేది సాఫ్ట్‌వేర్ పనితీరును ఎలా మెరుగుపరుస్తుందో వివరించు.")
])

# 2. మోడల్ ప్రారంభం
llm = ChatGoogleGenerativeAI(
    model="gemini-1.5-flash",
    temperature=0.2,
    google_api_key=os.getenv("GEMINI_API_KEY")
)

# 3. అవుట్‌పుట్ పార్సర్ (కేవలం టెక్స్ట్ స్ట్రింగ్ మాత్రమే బయటకు తెస్తుంది)
parser = StrOutputParser()

# 4. LCEL పైప్ నిర్మాణం! (ఎంత నీట్‌గా ఉందో చూడండి)
chain = prompt_template | llm | parser

# చైన్‌ను ఎగ్జిక్యూట్ చేయడం
response = chain.invoke({"concept": "Asyncio Event Loops"})
print("--- LCEL చైన్ సమాధానం ---")
print(response)
```

## 3. LlamaIndex: డాక్యుమెంట్ల స్పెషలిస్ట్

LangChain అన్ని రకాల పనులకూ పనికొస్తే, **LlamaIndex** అనేది ప్రత్యేకంగా **డేటా మరియు డాక్యుమెంట్ సెర్చ్ కోసం** పుట్టింది.
- ఇది డాక్యుమెంట్లను **Nodes** గా విభజించి, వాటి సంబంధాలను భద్రపరుస్తుంది.
- Notion, Google Drive, Jira లాంటి 100+ సోర్సెస్ నుండి డేటాను క్షణంలో చదవగలదు.
- కేవలం **3 లైన్ల కోడ్‌తో** పూర్తి స్థాయి RAG సెర్చ్ ఇంజిన్‌ను తయారు చేయవచ్చు:

```python
from llama_index.core import Document, VectorStoreIndex

# 1. డాక్యుమెంట్లు సృష్టించడం
docs = [
    Document(text="టీచిన్ గ్లోబల్ ఉద్యోగులకు వర్క్-ఫ్రమ్-హోమ్ అలవెన్స్ కింద ₹1,50,000 ఇస్తుంది.", metadata={"topic": "benefits"}),
    Document(text="ఉద్యోగులు ప్రతి 24 నెలలకు ఒకసారి కొత్త ల్యాప్‌టాప్ తీసుకోవచ్చు.", metadata={"topic": "hardware"})
]

# 2. వెక్టర్ ఇండెక్స్ నిర్మించడం (చంకింగ్, ఎంబెడ్డింగ్ అన్నీ ఆటోమేటిక్‌గా చేసేస్తుంది!)
index = VectorStoreIndex.from_documents(docs)

# 3. క్వెరీ ఇంజిన్ ప్రారంభం
query_engine = index.as_query_engine()

# 4. ప్రశ్న అడగడం
response = query_engine.query("హోమ్ ఆఫీస్ అలవెన్స్ ఎంత?")
print("\n--- లామాఇండెక్స్ సమాధానం ---")
print(response)
```

## 4. LangChain vs LlamaIndex: ఏది ఎప్పుడు వాడాలి?

| కొలమానం | LangChain | LlamaIndex |
| :--- | :--- | :--- |
| **ప్రధాన ఉద్దేశం** | మొత్తం ఆర్కెస్ట్రేషన్ మరియు ఏజెంట్లు (Agents) నిర్మించడం | డాక్యుమెంట్లను లోతుగా విశ్లేషించడం మరియు వెతకడం (Search) |
| **దేనికి బెస్ట్?** | సంక్లిష్టమైన ఏజెంట్ పనులు, టూల్స్ వాడటం, చాట్‌బాట్స్ | పెద్ద పెద్ద PDF లు, టేబుల్స్, స్ప్రెడ్‌షీట్లను శోధించడం |
| **కస్టమ్ చైన్స్** | అద్భుతం (**LCEL** పైప్ సింటాక్స్) | సాధారణం |
| **ఏజెంట్ ఫ్రేమ్‌వర్క్** | **LangGraph** (ఆధునిక సైక్లిక్ వర్క్‌ఫ్లోలు) | LlamaAgents |
| **కంపెనీలలో రియల్ ప్రాక్టీస్** | రెండింటినీ కలిపి వాడతారు! ఇండెక్సింగ్ కోసం LlamaIndex, ఏజెంట్ లాజిక్ కోసం LangChain/LangGraph. |

## 5. ఫ్రెషర్స్ చేసే సాధారణ తప్పులు (Common Pitfalls)

1. **పాత లాంగ్‌చైన్ ట్యుటోరియల్స్ చూడటం:**
   - ⚠️ ఇంటర్నెట్‌లో పాత `LLMChain`, `initialize_agent` అని ఉన్న కోడ్ చూడకండి. ఆధునిక లాంగ్‌చైన్‌లో ప్రతిదీ **LCEL (`prompt | model | parser`)** మరియు **LangGraph** లోనే రాయాలి.
2. **అనవసరమైన చోట్ల ఫ్రేమ్‌వర్క్స్ వాడటం:**
   - కేవలం ఒక్క ప్రశ్న అడగడానికి లాంగ్‌చైన్ అవసరం లేదు; నేరుగా Google GenAI SDK సరిపోతుంది. మల్టీ-స్టెప్ పైప్‌లైన్లు ఉన్నప్పుడు మాత్రమే ఫ్రేమ్‌వర్క్స్ వాడాలి.
3. **స్ట్రీమింగ్ కోసం పెద్ద కోడ్ రాయడం:**
   - LCEL లో ఆటోమేటిక్‌గా `.stream()` సపోర్ట్ ఉంటుంది; అదనపు కోడ్ రాయనవసరం లేదు.

## 6. ప్రాక్టీస్ ల్యాబ్ (Daily Hands-On Lab)

### 🧪 టాస్క్: బహుళ దశల కస్టమర్ ఫీడ్‌బ్యాక్ విశ్లేషణ పైప్‌లైన్
**సన్నివేశం:** కస్టమర్ తెలుగులో లేదా ఏ భాషలోనైనా రాసిన కంప్లైంట్‌ను చదివి, అందులోని ముఖ్యమైన సమస్యలను గుర్తించి, వాటిని బోర్డ్ రూమ్ ఎగ్జిక్యూటివ్‌లకు అర్థమయ్యే అధికారిక ఇంగ్లీష్ బ్రీఫింగ్‌గా మార్చే LCEL చైన్ రాయండి.

```python
# =========================================================
# Day 28 Lab: బహుళ దశల LCEL ట్రాన్స్‌ఫార్మేషన్ పైప్‌లైన్
# =========================================================
import os
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_google_genai import ChatGoogleGenerativeAI

llm = ChatGoogleGenerativeAI(
    model="gemini-1.5-flash",
    temperature=0.0,
    google_api_key=os.getenv("GEMINI_API_KEY")
)

# 1వ దశ ప్రాంప్ట్: ప్రధాన సమస్యలను గుర్తించడం
extract_prompt = ChatPromptTemplate.from_template(
    "ఈ కస్టమర్ ఫీడ్‌బ్యాక్ చదివి, పరిష్కరించాల్సిన ముఖ్యమైన 2 సమస్యలను గుర్తించు:\n\n{feedback}"
)

# 2వ దశ ప్రాంప్ట్: అధికారిక ఇంగ్లీషులోకి మార్చడం
translate_prompt = ChatPromptTemplate.from_template(
    "కింది సమస్యలను బోర్డ్ మీటింగ్‌లో సమర్పించేలా అధికారిక ఎగ్జిక్యూటివ్ ఇంగ్లీషులోకి మార్చు:\n\n{complaints}"
)

# రెండు దశలను కలిపి ఒకే పైప్‌లైన్‌గా నిర్మించడం
extraction_chain = extract_prompt | llm | StrOutputParser()
full_pipeline = (
    {"complaints": extraction_chain}
    | translate_prompt
    | llm
    | StrOutputParser()
)

sample_raw_feedback = """
ఈ యాప్ నిన్నటి నుండి చాలా స్లోగా ఉంది. నేను పేమెంట్ చేస్తుంటే మధ్యలోనే యాప్ క్లోజ్ అయిపోయింది! 
మళ్లీ ఓపెన్ చేస్తే అమౌంట్ కట్ అయింది కానీ టికెట్ రాలేదు. వెంటనే రీఫండ్ ఇప్పించండి!
"""

print("మల్టీ-స్టేజ్ LCEL చైన్ రన్ అవుతోంది...")
result = full_pipeline.invoke({"feedback": sample_raw_feedback})

print("\n" + "="*50)
print("ఎగ్జిక్యూటివ్ ఇన్సిడెంట్ బ్రీఫింగ్ (ENGLISH)")
print("="*50)
print(result)
print("="*50)
```

## 7. ఇంటర్వ్యూలలో అడిగే ప్రశ్నలు (Interview Questions & Answers)

1. **ప్రశ్న: LCEL (LangChain Expression Language) అంటే ఏమిటి? దాని ప్రయోజనాలు ఏమిటి?**
   - **సమాధానం:** LCEL అనేది యునిక్స్ పైప్ (`|`) ఆధారంగా కాంపోనెంట్లను కనెక్ట్ చేసే ఆధునిక లాంగ్‌చైన్ సింటాక్స్ (`prompt | model | parser`). ఇది సింక్రోనస్, అసమకాలిక (`ainvoke`), స్ట్రీమింగ్ (`astream`), బ్యాచింగ్ (`batch`) మరియు లూప్‌లను ఎలాంటి అదనపు కోడ్ లేకుండా ఆటోమేటిక్‌గా సపోర్ట్ చేస్తుంది.
2. **ప్రశ్న: LangChain కంటే LlamaIndex ను ఎప్పుడు ఎంచుకోవాలి?**
   - **సమాధానం:** ప్రాజెక్ట్ యొక్క ప్రధాన సవాలు **సమాచార నిర్వహణ మరియు డాక్యుమెంట్ సెర్చ్** అయినప్పుడు LlamaIndex ను ఎంచుకోవాలి. ముఖ్యంగా టేబుల్స్ ఉన్న సంక్లిష్టమైన PDF లు, పవర్ పాయింట్ ప్రెజెంటేషన్లు మరియు క్రమానుగత డాక్యుమెంట్ ఇండెక్సింగ్ కోసం LlamaIndex అత్యుత్తమం. ఏజెంట్లు, టూల్ రూటింగ్ మరియు సాధారణ వర్క్‌ఫ్లోల కోసం LangChain బెటర్.
3. **ప్రశ్న: లాంగ్‌చైన్‌లో Output Parser ఏం చేస్తుంది?**
   - **సమాధానం:** మోడల్ తిరిగి ఇచ్చే రా టెక్స్ట్ లేదా మెసేజ్ ఆబ్జెక్ట్‌ను తీసుకొని, దాన్ని క్రింది అప్లికేషన్‌కు అవసరమైన ఫార్మాట్‌లోకి మారుస్తుంది (ఉదాహరణకి `StrOutputParser` టెక్స్ట్ మాత్రమే ఇస్తుంది; `JsonOutputParser` లేదా `PydanticOutputParser` ఆ టెక్స్ట్‌ను పార్స్ చేసి టైప్-సేఫ్ ఆబ్జెక్ట్‌గా అందిస్తాయి).
