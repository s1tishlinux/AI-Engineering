## 1. సాఫ్ట్‌వేర్‌లో నిర్ణయాలు & పునరావృతం (The "Why")

కంప్యూటర్లకు సొంతంగా ఆలోచించే తెలివితేటలు ఉండవు; కానీ అవి అత్యంత వేగంగా లెక్కలు వేస్తాయి. సాఫ్ట్‌వేర్ పవర్‌ఫుల్ కావడానికి రెండు ముఖ్యమైన అంశాలు కారణం:
1. **నిర్ణయాలు తీసుకోవడం (Decision Making):** *"ఒక కస్టమర్ క్రెడిట్ స్కోర్ 750 కంటే ఎక్కువ ఉంటే లోన్ అప్రూవ్ చెయ్యి, లేదంటే రిజెక్ట్ చెయ్యి."*

ఆపరేటర్లు మరియు లూప్స్ లేకుండా ఏ ప్రోగ్రామ్ కూడా తెలివిగా పనిచేయలేదు!

## 2. ఆపరేటర్లు (Operators in Python)

### A. అంకగణిత ఆపరేటర్లు (Arithmetic Operators)
| ఆపరేటర్ | పేరు | ఉదాహరణ | ఫలితం (Result) |
| :--- | :--- | :--- | :--- |
| `+` | కూడిక (Addition) | `10 + 5` | `15` |
| `-` | తీసివేత (Subtraction) | `10 - 5` | `5` |
| `*` | గుణకారం (Multiplication) | `10 * 5` | `50` |
| `/` | డివిజన్ (Division) | `10 / 4` | `2.5` (ఎల్లప్పుడూ float వస్తుంది) |
| `//` | ఫ్లోర్ డివిజన్ (Floor Division) | `10 // 4` | `2` (దశాంశాన్ని తీసేస్తుంది) |
| `%` | మోడ్యులో (Modulo - శేషం) | `10 % 3` | `1` (సరి/బేసి సంఖ్యలు గుర్తించడానికి) |
| `**` | ఘాతం (Power) | `2 ** 3` | `8` ($2^3 = 8$) |

### B. పోలిక మరియు లాజికల్ ఆపరేటర్లు (Comparison & Logical)
- **Comparison (పోలిక):** `==` (సమానమా?), `!=` (సమానం కాదా?), `>`, `<`, `>=`, `<=`
- **Logical (లాజిక్):** `and` (రెండూ నిజమైతేనే True), `or` (ఏదో ఒకటి నిజమైనా True), `not` (వ్యతిరేకం చేస్తుంది)
- **Membership:** `in`, `not in` (ఒక లిస్ట్‌లో ఆ ఐటమ్ ఉందా లేదా అని చూస్తుంది)

```python
# రియల్ వరల్డ్ అకౌంట్ లాగిన్ లాజిక్
user_role = "Admin"
has_2fa_enabled = True
is_account_locked = False

# అడ్మిన్ లేదా సూపర్ యూజర్ అయి ఉండి, 2FA ఆన్ లో ఉండి, అకౌంట్ లాక్ కాకుండా ఉండాలి:
can_access = (user_role == "Admin" or user_role == "SuperUser") and has_2fa_enabled and not is_account_locked
print(f"డేటాబేస్ యాక్సెస్ లభించిందా?: {can_access}")  # True
```

## 3. కండిషనల్ స్టేట్‌మెంట్స్ (`if`, `elif`, `else`)

### సులభమైన ఉదాహరణ: ట్రాఫిక్ సిగ్నల్
- `if గ్రీన్ లైట్`: వాహనాన్ని ముందుకు పోనివ్వు.
- `elif ఎల్లో లైట్`: వేగం తగ్గించి ఆగడానికి సిద్ధపడు.
- `else`: పూర్తిగా ఆగిపో.

```python
# ఈ-కామర్స్ వెబ్‌సైట్‌లో డిస్కౌంట్ ఇచ్చే లాజిక్
cart_total = 3200  # రూపాయలు

if cart_total >= 5000:
    discount_percent = 25
elif cart_total >= 2500:
    discount_percent = 15
elif cart_total >= 1000:
    discount_percent = 5
else:
    discount_percent = 0

discount_amount = cart_total * (discount_percent / 100)
final_price = cart_total - discount_amount

print(f"మొత్తం బిల్లు: ₹{cart_total} | డిస్కౌంట్: {discount_percent}% (₹{discount_amount}) | చెల్లించాల్సినది: ₹{final_price}")
```

## 4. లూప్‌లు: `for` మరియు `while` (Loops)

### A. `for` లూప్: ఎన్నిసార్లు చేయాలో ముందే తెలిసినప్పుడు
ఒక లిస్ట్ లేదా రేంజ్ ఉన్నప్పుడు `for` లూప్ వాడతాం.

```python
# range(start, stop) ఫంక్షన్: start నుండి (stop - 1) వరకు నడుస్తుంది
print("సర్వర్ బ్యాచ్ ప్రాసెసింగ్:")
for batch_id in range(1, 6):  # 1 నుండి 5 వరకు
    print(f"  → బ్యాచ్ నెంబర్ #{batch_id} పూర్తయింది.")

# సర్వర్ల లిస్ట్ చెక్ చేయడం
servers = ["web-prod-01", "web-prod-02", "db-prod-01"]
for server in servers:
    print(f"సర్వర్ {server} రన్ అవుతోంది... Status: 200 OK")
```

### B. `while` లూప్: కండిషన్ తప్పు అయ్యేంత వరకు నడపడానికి
ఒక పని ఎన్నిసార్లు జరుగుతుందో ముందే తెలియనప్పుడు (ఉదాహరణకి నెట్‌వర్క్ కనెక్ట్ అయ్యేంత వరకు వేచి చూడటం) `while` లూప్ వాడతాం.

```python
# పేమెంట్ గేట్‌వే రీ-ట్రై (Retry) లాజిక్
max_attempts = 3
attempt = 1
is_connected = False

while attempt <= max_attempts and not is_connected:
    print(f"పేమెంట్ సర్వర్‌కి కనెక్ట్ అవుతున్నాం (ప్రయత్నం #{attempt})...")
    # 2వ ప్రయత్నంలో సక్సెస్ అయిందని అనుకుందాం
    if attempt == 2:
        is_connected = True
        print("  ✅ కనెక్షన్ విజయవంతమైంది!")
    attempt += 1

if not is_connected:
    print("  ❌ సర్వర్ స్పందించడం లేదు. ఇంజనీర్లకి అలర్ట్ పంపుతున్నాం!")
```

## 5. లూప్‌లను ఆపడం: `break`, `continue`, `pass`

- `break`: లూప్ మధ్యలోనే పూర్తిగా బయటకు వచ్చేస్తుంది.
- `continue`: ప్రస్తుత స్టెప్‌ని మాత్రమే స్కిప్ చేసి, వెంటనే తర్వాతి స్టెప్‌కి వెళ్తుంది.
- `pass`: కోడ్ స్ట్రక్చర్ కోసం ఖాళీగా ఉంచే ప్లేస్‌హోల్డర్ (ఏమీ చేయదు).

```python
# సర్వర్ లాగ్స్ తనిఖీ చేయడం
log_lines = ["INFO: సిస్టమ్ బాగుంది", "DEBUG: కాష్ రిఫ్రెష్", "ERROR: డేటాబేస్ ఆగిపోయింది", "INFO: పూర్తయింది"]

for log in log_lines:
    if "DEBUG" in log:
        continue  # DEBUG లాగ్స్ ని పట్టించుకోవద్దు, స్కిప్ చెయ్యి
    
    if "ERROR" in log:
        print(f"🚨 ప్రమాదం! వెంటనే లూప్ ఆపేసి అలర్ట్ ఇవ్వండి: {log}")
        break     # ఎర్రర్ రాగానే వెంటనే లూప్ ఆపేస్తాం
```

## 6. ఫ్రెషర్స్ చేసే సాధారణ తప్పులు (Common Pitfalls)

1. **`=` మరియు `==` తేడా మర్చిపోవడం:**
   - `=` అనేది విలువను ఇవ్వడానికి (Assignment - `x = 10`).
   - `==` అనేది రెండు సమానమా కాదా అని చెక్ చేయడానికి (`if x == 10:`).
2. **అనంతమైన లూప్‌లు (Infinite While Loops):**
   - `while` లూప్‌లో కౌంటర్ పెంచడం (`count += 1`) మర్చిపోతే ప్రోగ్రామ్ ఆగకుండా తిరుగుతూనే ఉంటుంది.
3. **`range()` లో చివరి నెంబర్:**
   - `range(1, 10)` అంటే 1 నుండి 9 వరకే తీసుకుంటుంది, 10ని తీసుకోదు!

## 7. ప్రాక్టీస్ ల్యాబ్ (Daily Hands-On Lab)

### 🧪 టాస్క్: ATM క్యాష్ విత్‌డ్రా & పిన్ వెరిఫికేషన్ ప్రోగ్రామ్
**సన్నివేశం:** యూజర్‌కి సరైన పిన్ (1234) ఎంటర్ చేయడానికి 3 అవకాశాలు ఇవ్వాలి. పిన్ సరిగ్గా ఉంటే బ్యాలెన్స్ చెక్ లేదా డబ్బులు విత్‌డ్రా చేసుకునే ఆప్షన్లు ఇవ్వాలి.

```python
# ==========================================
# Day 2 Lab: ATM మిషన్ సిమ్యులేషన్
# ==========================================

CORRECT_PIN = "1234"
account_balance = 25000.0
max_attempts = 3
authenticated = False

print("🏦 టీచిన్ గ్లోబల్ బ్యాంక్ ATM కి స్వాగతం")

for attempt in range(1, max_attempts + 1):
    pin_input = input(f"మీ 4-అంకెల పిన్ నమోదు చేయండి (ప్రయత్నం {attempt}/{max_attempts}): ")
    if pin_input == CORRECT_PIN:
        authenticated = True
        print("\n✅ పిన్ ధృవీకరించబడింది!\n")
        break
    else:
        remaining = max_attempts - attempt
        print(f"❌ తప్పుడు పిన్. మిగిలిన ప్రయత్నాలు: {remaining}")

if not authenticated:
    print("🚨 3 సార్లు తప్పుగా ఎంటర్ చేయడం వల్ల మీ కార్డు తాత్కాలికంగా బ్లాక్ చేయబడింది.")
else:
    print("1. బ్యాలెన్స్ చెక్ చేయండి")
    print("2. నగదు విత్‌డ్రా చేసుకోండి")
    choice = input("ఒక ఆప్షన్‌ను ఎంచుకోండి (1 లేదా 2): ")

    if choice == "1":
        print(f"మీ ఖాతాలోని ప్రస్తుత బ్యాలెన్స్: ₹{account_balance:,.2f}")
    elif choice == "2":
        withdraw_amount = float(input("విత్‌డ్రా చేయాల్సిన మొత్తం ఇవ్వండి (₹500 గుణిజాలు): "))
        if withdraw_amount <= 0:
            print("❌ సరైన మొత్తాన్ని నమోదు చేయండి.")
        elif withdraw_amount % 500 != 0:
            print("❌ మొత్తం ₹500 నోట్లలో మాత్రమే విత్‌డ్రా చేయగలరు.")
        elif withdraw_amount > account_balance:
            print(f"❌ మీ ఖాతాలో సరిపడా డబ్బు లేదు! మీ బ్యాలెన్స్: ₹{account_balance:,.2f}")
        else:
            account_balance -= withdraw_amount
            print(f"💵 ₹{withdraw_amount:,.2f} విత్‌డ్రా విజయవంతమైంది. నగదు తీసుకోండి!")
            print(f"మిగిలిన బ్యాలెన్స్: ₹{account_balance:,.2f}")
    else:
        print("❌ తప్పుడు ఆప్షన్ ఎంచుకున్నారు.")
```

## 8. ఇంటర్వ్యూలలో అడిగే ప్రశ్నలు (Interview Questions & Answers)

1. **ప్రశ్న: `break` మరియు `continue` మధ్య తేడా ఏమిటి?**
   - **సమాధానం:** `break` అనేది మొత్తం లూప్‌ని వెంటనే ఆపేసి బయటకు వస్తుంది. `continue` అనేది ప్రస్తుత ఇటరేషన్‌ని మాత్రమే ఆపి, ఆ లూప్‌లోని తర్వాతి ఇటరేషన్‌ని కొనసాగిస్తుంది.
2. **ప్రశ్న: పైథాన్‌లో షార్ట్-సర్క్యూట్ ఇవాల్యుయేషన్ (Short-Circuit Evaluation) అంటే ఏమిటి?**
   - **సమాధానం:** లాజికల్ ఎక్స్‌ప్రెషన్లలో ఫలితం ముందే ఖరారైతే పైథాన్ మిగిలిన భాగాన్ని చెక్ చేయదు. ఉదాహరణకు `False and something` లో మొదటిదే False కాబట్టి రెండోది చెక్ చేయదు. అలాగే `True or something` లో మొదటిదే True కాబట్టి రెండోది చెక్ చేయదు.
3. **ప్రశ్న: పైథాన్‌లో `pass` స్టేట్‌మెంట్ ఎందుకు వాడతారు?**
   - **సమాధానం:** పైథాన్‌లో సింటాక్స్ ఎర్రర్ రాకుండా ఉండటానికి ఖాళీగా ఉంచే ప్లేస్‌హోల్డర్ `pass`. భవిష్యత్తులో కోడ్ రాయాలనుకున్నప్పుడు ఒక ఫంక్షన్ లేదా లూప్ లోపల `pass` రాసి ఉంచుతాం.
