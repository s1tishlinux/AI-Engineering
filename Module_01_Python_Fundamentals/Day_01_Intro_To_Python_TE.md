## 1. అసలు "పైథాన్ ఎందుకు?" (The Real-World "Why")

ఒక చిన్న ఉదాహరణ చూద్దాం. మీరు ఒక కంపెనీలో AI చాట్‌బాట్ లేదా ఒక వెబ్ సర్వీస్ తయారు చేయాలనుకుంటున్నారు.
- అదే **C++** లేదా **Java** లో అయితే, కేవలం ఒక ఫైల్ చదవడానికే క్లాసులు, మెయిన్ మెథడ్లు, మెమొరీ కేటాయింపులు అంటూ 15 నుండి 20 లైన్ల కోడ్ రాయాల్సి ఉంటుంది.
- కానీ **పైథాన్** లో, మనం మనసులో ఏమైతే ఇంగ్లీషులో ఆలోచిస్తామో, దాదాపు అదే విధంగా కేవలం 2 లైన్లలో రాసేయవచ్చు:

```python
# పైథాన్‌లో ఫైల్ చదవడం ఎంత సింపుల్ చూడండి:
with open("data.txt") as file:
    print(file.read())
```

## 3. ప్రాథమిక కాన్సెప్ట్‌లు & సింటాక్స్ (Core Concepts & Syntax)

### కాన్సెప్ట్ 1: ఇండెంటేషన్ (Indentation - పైథాన్ సిగ్నేచర్ రూల్)
C లేదా Java లాంటి భాషల్లో కోడ్ బ్లాక్‌లను గుర్తించడానికి కర్లీ బ్రాకెట్స్ `{ }` వాడతారు. కానీ పైథాన్‌లో బ్రాకెట్స్ ఉండవు! దానికి బదులుగా **స్పేసెస్ (Spaces - ఖాళీలు)** వాడతారు. సాధారణంగా 4 స్పేస్‌లు ఉపయోగిస్తాం.

```python
# ✅ సరైన పద్ధతి (Correct: 4 Spaces ఇండెంటేషన్)
is_logged_in = True
if is_logged_in:
    print("టీచిన్ ప్లాట్‌ఫారమ్‌కి స్వాగతం!")
    print("మీ డాష్‌బోర్డ్ సిద్ధంగా ఉంది.")

# ❌ తప్పు పద్ధతి (IndentationError వస్తుంది)
# if is_logged_in:
# print("ఇలా స్పేస్ ఇవ్వకుండా రాస్తే ఎర్రర్ వస్తుంది!")
```

### కాన్సెప్ట్ 2: వేరియబుల్స్ & డైనమిక్ టైపింగ్ (Variables & Dynamic Typing)
C/Java లో `int age = 22;` అని డేటా టైప్ ముందుగానే చెప్పాలి. కానీ పైథాన్‌లో మనం ఏ రకం డేటా ఇస్తున్నామో అది ఆటోమేటిక్‌గా గుర్తిస్తుంది (**Dynamic Typing**).

#### సులభమైన ఉదాహరణ:
పైథాన్‌లో వేరియబుల్ అంటే ఏదో డబ్బా కాదు. అది మెమొరీలో ఉన్న ఒక విలువకు మనం అతికించే **స్టిక్కర్ / నేమ్‌ట్యాగ్ (Name Tag)** లాంటిది!

```python
# పూర్ణ సంఖ్య (Integer)
student_age = 22

# దశాంశ సంఖ్య (Float)
course_fee = 4999.50

# అక్షరాలు / టెక్స్ట్ (String)
student_name = "రాహుల్ వర్మ"

# అవును / కాదు (Boolean: True లేదా False - మొదటి అక్షరం Capital ఉండాలి)
is_enrolled = True

# విలువ ఏమీ లేకపోతే (NoneType)
certificate_id = None

# ఏ వేరియబుల్ ఏ డేటా టైపో తెలుసుకోవడానికి type() వాడతాం:
print(type(student_age))   # Output: <class 'int'>
print(type(course_fee))    # Output: <class 'float'>
print(type(student_name))  # Output: <class 'str'>
print(type(is_enrolled))   # Output: <class 'bool'>
```

### కాన్సెప్ట్ 3: ఇన్‌పుట్ & అవుట్‌పుట్ (Input, Output & Type Casting)

మనం కీబోర్డ్ ద్వారా డేటాను తీసుకోవడానికి `input()` ఉపయోగిస్తాం.
⚠️ **గుర్తుంచుకోవాల్సిన విషయం:** `input()` ద్వారా మనం ఏమి ఇచ్చినా, పైథాన్ దానిని **String (టెక్స్ట్)** గా మాత్రమే తీసుకుంటుంది!

```python
# అవుట్‌పుట్ డిస్‌ప్లే చేయడం
print("హలో! పైథాన్ మొదటి రోజు క్లాస్‌కి స్వాగతం!")

# యూజర్ నుండి డేటా తీసుకోవడం
user_name = input("మీ పేరు నమోదు చేయండి: ")
user_age_str = input("మీ వయస్సు ఎంత?: ")

# ❌ ఫ్రెషర్స్ సాధారణంగా చేసే తప్పు:
# next_year_age = user_age_str + 1
# TypeError వస్తుంది! ఎందుకంటే String ని మరియు Number ని డైరెక్ట్‌గా కలపలేము.

# ✅ సరైన పరిష్కారం: టైప్ కాస్టింగ్ (Type Casting)
user_age = int(user_age_str)  # String ని Integer గా మార్చడం
next_year_age = user_age + 1

# లేటెస్ట్ పైథాన్ ఫార్మాటింగ్ (f-strings)
print(f"నమస్కారం {user_name}! వచ్చే సంవత్సరానికి మీ వయస్సు {next_year_age} సంవత్సరాలు అవుతుంది.")
```

## 4. ఫ్రెషర్స్ చేసే సాధారణ తప్పులు (Common Pitfalls)

1. **స్పేస్‌లు మరియు ట్యాబ్‌లు కలపడం:** ఎల్లప్పుడూ 4 స్పేస్‌లనే వాడండి. VS Code లో `Tab` ప్రెస్ చేస్తే ఆటోమేటిక్‌గా సరిపోతుంది.
2. **Boolean తప్పుగా రాయడం:** పైథాన్‌లో `true` లేదా `false` అని చిన్న అక్షరాలతో రాయకూడదు. `True` మరియు `False` అని మొదటి అక్షరం పెద్దది (Capital) ఉండాలి.
3. **ఇన్‌పుట్ తీసుకున్నప్పుడు నెంబర్ గా మార్చకపోవడం:** `input()` ఎప్పుడూ టెక్స్ట్‌నే ఇస్తుంది. గణిత లెక్కలు చేయాలంటే `int()` లేదా `float()` గా మార్చడం మర్చిపోవద్దు.

## 5. ప్రాక్టీస్ ల్యాబ్ (Daily Hands-On Lab)

### 🧪 టాస్క్: ఫ్రెషర్ జీతం లెక్కింపు ప్రోగ్రామ్ (Salary Calculator)
**సన్నివేశం:** ఒక కొత్త ఫ్రెషర్ కంపెనీలో జాయిన్ అవుతున్నారు. వారి వార్షిక ప్యాకేజీ (Annual CTC) ఆధారంగా నెలవారీ చేతికి వచ్చే జీతాన్ని (Monthly In-hand Salary) లెక్కించాలి.

```python
# ==========================================
# Day 1 Lab: ఫ్రెషర్ శాలరీ కాలిక్యులేటర్
# ==========================================

candidate_name = input("అభ్యర్థి పేరు నమోదు చేయండి: ")
annual_ctc = float(input("వార్షిక ప్యాకేజీ లక్షల్లో ఇవ్వండి (ఉదాహరణకి 6.5): "))

# లెక్కలు
monthly_gross = (annual_ctc * 100000) / 12
tax_deduction = monthly_gross * 0.10  # 10% పన్ను మినహాయింపు (TDS)
monthly_in_hand = monthly_gross - tax_deduction

print("\n" + "="*45)
print(f"శాలరీ వివరాలు : {candidate_name.upper()}")
print("="*45)
print(f"వార్షిక ప్యాకేజీ  : ₹{annual_ctc:.2f} Lakhs")
print(f"నెలవారీ గ్రాస్    : ₹{monthly_gross:,.2f}")
print(f"అంచనా పన్ను (10%): ₹{tax_deduction:,.2f}")
print(f"చేతికి వచ్చే జీతం : ₹{monthly_in_hand:,.2f}")
print("="*45)
```

## 6. ఇంటర్వ్యూలలో అడిగే ప్రశ్నలు (Interview Questions & Answers)

1. **ప్రశ్న: పైథాన్ ఇంటర్‌ప్రిటెడ్ లాంగ్వేజా (Interpreted) లేక కంపైల్డ్ లాంగ్వేజా (Compiled)?**
   - **సమాధానం:** పైథాన్ రెండూనూ! మనం రాసిన కోడ్ మొదట ఇంటర్మీడియట్ బైట్‌కోడ్ (`.pyc`) గా కంపైల్ అవుతుంది. ఆ తర్వాత పైథాన్ వర్చువల్ మెషీన్ (PVM) దానిని లైన్-బై-లైన్ ఇంటర్‌ప్రిట్ చేసి రన్ చేస్తుంది.
2. **ప్రశ్న: పైథాన్‌లో డైనమిక్ టైపింగ్ (Dynamic Typing) అంటే ఏమిటి?**
   - **సమాధానం:** మనం వేరియబుల్స్ క్రియేట్ చేసేటప్పుడు వాటి డేటా టైప్‌లను (int, float, str) ముందుగా చెప్పాల్సిన అవసరం లేదు. వేరియబుల్‌కి ఇచ్చే వాల్యూ ఆధారంగా రన్‌టైమ్‌లో పైథాన్ ఆటోమేటిక్‌గా టైప్‌ని నిర్ణయిస్తుంది.
3. **ప్రశ్న: పైథాన్‌లో `/` కి మరియు `//` కి తేడా ఏమిటి?**
   - **సమాధానం:** `/` అనేది ఫ్లోట్ డివిజన్ (Float Division - ఉదా: `7 / 2 = 3.5`), కానీ `//` అనేది ఫ్లోర్ డివిజన్ (Floor Division - ఉదా: `7 // 2 = 3` డెసిమల్ తర్వాత ఉన్న నెంబర్లను తీసేస్తుంది).
