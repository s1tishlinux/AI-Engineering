## 1. ఆటోరిగ్రెసివ్ ఇంజిన్ అంటే ఏమిటి? (The "Why")

పాతకాలపు ML కేవలం ఒక సంఖ్యను లేదా కేటగిరీని మాత్రమే ఇచ్చేది:
- `ఈ ఈమెయిల్ స్పామా? -> అవును (1)`
- `ఇంటి ధర ఎంత? -> ₹75 లక్షలు`

కానీ జనరేటివ్ AI సరికొత్త కథనాలు, పైథాన్ కోడ్, SQL క్వెరీలు మరియు వ్యాసాలను సొంతంగా సృష్టించగలదు.
అయితే, ప్రపంచంలోని ఎంత పెద్ద LLM అయినా అంతర్గతంగా చేసేది కేవలం ఒకే ఒక్క పని: **"తర్వాతి పదాన్ని (Next-Token) ఊహించడం!"**

```
మనం ఇచ్చిన ప్రాంప్ట్: "భారతదేశ రాజధాని నగరం"
మోడల్ తన వద్ద ఉన్న 1,00,000 టోకెన్లలో సంభావ్యతను లెక్కిస్తుంది:
  - "న్యూఢిల్లీ" : 94.2%  <── అత్యధిక అవకాశం!
  - "హైదరాబాద్" :  3.1%
  - "ముంబై"     :  1.5%
మోడల్ "న్యూఢిల్లీ" ని ఎంచుకుని వాక్యానికి జతచేసి, తర్వాతి పదం కోసం మళ్లీ లెక్కిస్తుంది!
```

## 2. LLM మోడల్‌ను ఎలా తయారు చేస్తారు? (3 దశల ప్రక్రియ)

ఇంటర్వ్యూలలో ప్రతి ఫ్రెషర్‌ని అడిగే అతి ముఖ్యమైన కాన్సెప్ట్:

```
┌─────────────────────────────────┐
│ 1. ప్రీ-ట్రైనింగ్ (Pretraining) │  ఇంటర్నెట్‌లోని లక్షల కోట్ల టెక్స్ట్‌ను వేలాది GPU లపై
│ ప్రపంచ జ్ఞానాన్ని గ్రహిస్తుంది  │  చదువుతుంది. కేవలం వాక్యాలను పూర్తి చేస్తుంది (చాట్ చేయలేదు!)
└────────────────┬────────────────┘
                 ▼
┌─────────────────────────────────┐
│ 2. ఫైన్-ట్యూనింగ్ (SFT)          │  మనుషులు స్వయంగా రాసిన ప్రశ్న-సమాధానాలతో ట్రైన్ అవుతుంది.
│ ఆదేశాలను పాటించడం నేర్చుకుంటుంది │  దీనివల్ల అది ఒక "Instruct" మోడల్‌గా (చాట్‌బాట్‌గా) మారుతుంది.
└────────────────┬────────────────┘
                 ▼
┌─────────────────────────────────┐
│ 3. అలైన్‌మెంట్ (RLHF / DPO)     │  హ్యూమన్ ఫీడ్‌బ్యాక్ ద్వారా సురక్షితమైన ప్రవర్తన నేర్పుతారు.
│ రక్షణ, మర్యాద మరియు సేఫ్టీ       │  ప్రమాదకరమైన ప్రశ్నలకు (బాంబులు, వైరస్‌లు) సమాధానాలు చెప్పకుండా ఆపుతుంది.
└─────────────────────────────────┘
```

## 4. కాంటెక్స్ట్ విండో (Context Window - AI స్వల్పకాలిక జ్ఞాపకశక్తి)

- **కాంటెక్స్ట్ విండో:** ఒకేసారి మోడల్‌కి మనం ఎంత సమాచారాన్ని పంపగలమో చెప్పే పరిమితి (మనం అడిగే ప్రశ్న + పాత చాట్ హిస్టరీ + పంపిన డాక్యుమెంట్స్).
  - GPT-3.5 (2022): 4,000 టోకెన్లు (~3 పేజీలు)
  - Claude 3.5 (2024): 2,00,000 టోకెన్లు (~150 పేజీలు)
  - Google Gemini 1.5 Pro (2024+): **20,00,000 టోకెన్లు (2 Million Tokens!)** — అంటే 1 గంట నిడివి గల పూర్తి వీడియోను, లేదా 60,000 లైన్ల కోడ్‌ను ఒకేసారి అర్థం చేసుకోగలదు!
- **లాస్ట్ ఇన్ ది మిడిల్ (Lost in the Middle):** మోడల్స్ సాధారణంగా ప్రారంభంలో మరియు చివరలో ఉన్న సమాచారాన్ని బాగా గుర్తుంచుకుంటాయి; మధ్యలో దాగి ఉన్న చిన్న సమాచారాన్ని కొన్నిసార్లు మిస్ చేయవచ్చు.

## 5. AI సృజనాత్మకతను నియంత్రించే స్విచ్‌లు (Inference Parameters)

```python
generation_config = {
    # 1. Temperature (0.0 నుండి 2.0 వరకు)
    # 0.0 = అత్యంత ఖచ్చితమైనది (కోడింగ్, మ్యాథ్స్, JSON ఫార్మాట్లకు ఇదే వాడాలి!)
    # 0.7 = సాధారణ చాటింగ్ కోసం
    # 1.5 = విపరీతమైన ఊహాశక్తి, కవిత్వం, కథలు రాయడానికి
    "temperature": 0.2,

    # 2. Top-P (Nucleus Sampling)
    # సంభావ్యత కలిపితే P వచ్చేంతవరకు ఉండే పదాలను మాత్రమే తీసుకుంటుంది.
    # Top-p = 0.95 అంటే అనవసరమైన, అర్థం లేని 5% పదాలను వదిలేస్తుంది.
    "top_p": 0.95,

    # 3. Top-K
    # కేవలం టాప్ K మోస్ట్ ప్రాబబుల్ పదాలలో నుండే ఎంపిక చేస్తుంది.
    "top_k": 40
}
```

## 6. ఫ్రెషర్స్ చేసే సాధారణ తప్పులు (Common Pitfalls)

1. **కోడింగ్ లేదా JSON కోసం ఎక్కువ Temperature పెట్టడం:**
   - JSON అవుట్‌పుట్ కావాల్సి వచ్చినప్పుడు `temperature=1.0` పెడితే బ్రాకెట్లు మిస్ అయిపోయి ఎర్రర్స్ వస్తాయి. JSON కోసం ఎప్పుడూ `temperature=0.0` లేదా `0.1` మాత్రమే వాడాలి.
2. **కాంటెక్స్ట్ విండోను శాశ్వత మెమొరీ అనుకోవడం:**
   - కాంటెక్స్ట్ విండో అనేది తాత్కాలిక RAM లాంటిది. చాట్ క్లోజ్ చేయగానే అంతా మాయమైపోతుంది. శాశ్వతంగా గుర్తుండాలంటే డేటాబేస్‌లో సేవ్ చేయాలి.
3. **LLM లైవ్ ఇంటర్నెట్ చూస్తుంది అనుకోవడం:**
   - బేస్ మోడల్స్ ట్రైనింగ్ ఆగిన రోజు వరకే వాటికి సమాచారం తెలుస్తుంది. ఈరోజు వార్తలు తెలియాలంటే RAG లేదా Tool Calling ద్వారా మాత్రమే సాధ్యం.

## 7. ప్రాక్టీస్ ల్యాబ్ (Daily Hands-On Lab)

### 🧪 టాస్క్: టెంపరేచర్ & ప్రాబబిలిటీ సిమ్యులేటర్
**సన్నివేశం:** టెంపరేచర్ పెంచినప్పుడు AI సృజనాత్మకత మరియు ఊహాశక్తి గణిత పరంగా ఎలా మారుతుందో చూపే ఒక పైథాన్ స్క్రిప్ట్ రాయండి.

```python
# =========================================================
# Day 21 Lab: టెంపరేచర్ & సాఫ్ట్‌మ్యాక్స్ సిమ్యులేటర్
# =========================================================
import numpy as np

def simulate_llm_token_sampling(logits: dict[str, float], temperature: float = 1.0) -> dict[str, float]:
    tokens = list(logits.keys())
    raw_scores = np.array(list(logits.values()))

    # టెంపరేచర్ స్కేలింగ్
    temp = max(temperature, 1e-4)
    scaled_scores = raw_scores / temp

    # సాఫ్ట్‌మ్యాక్స్ ద్వారా శాతాలుగా మార్చడం
    exp_scores = np.exp(scaled_scores - np.max(scaled_scores))
    probabilities = exp_scores / np.sum(exp_scores)

    return {token: np.round(prob * 100, 2) for token, prob in zip(tokens, probabilities)}

# వాక్యం: "ప్రోగ్రామర్ కోడ్‌ని డీబగ్ చేస్తూ ఒక _____ కనుగొన్నాడు"
candidate_logits = {
    "bug": 8.5,           # సాధారణ పదం
    "typo": 6.2,          # సహజమైన పదం
    "syntax_error": 5.8,
    "sandwich": 1.2,      # సంబంధం లేని పదం
    "dragon": 0.5         # పూర్తి భ్రమ (Hallucination)
}

print("="*60)
print("LLM టోకెన్ ఎంపిక ప్రక్రియ (Inference Simulation)")
print("="*60)

for temp in [0.1, 0.7, 1.5]:
    probs = simulate_llm_token_sampling(candidate_logits, temperature=temp)
    print(f"\n🌡️ Temperature = {temp}:")
    for token, percentage in sorted(probs.items(), key=lambda x: x[1], reverse=True):
        bar = "█" * int(percentage // 3)
        print(f"  • {token:15}: {percentage:5.1f}% | {bar}")
print("="*60)
```

## 8. ఇంటర్వ్యూలలో అడిగే ప్రశ్నలు (Interview Questions & Answers)

1. **ప్రశ్న: LLMs లో ప్రీ-ట్రైనింగ్ (Pretraining) మరియు ఫైన్-ట్యూనింగ్ (Fine-Tuning) మధ్య తేడా ఏమిటి?**
   - **సమాధానం:** **ప్రీ-ట్రైనింగ్** అనేది ఇంటర్నెట్‌లోని ట్రిలియన్ల కొద్దీ టెక్స్ట్‌పై మోడల్‌కు భాష మరియు ప్రాథమిక ప్రపంచ పరిజ్ఞానాన్ని నేర్పే ప్రక్రియ; దీనికి కొన్ని వేల GPU లు మరియు మిలియన్ల డాలర్లు ఖర్చవుతాయి. **ఫైన్-ట్యూనింగ్** అనేది ఇప్పటికే ట్రైన్ అయిన మోడల్‌కు ఒక నిర్దిష్ట పనిని (ఉదాహరణకి కస్టమర్ సర్వీస్ లేదా మెడికల్ సలహాలు) నేర్పించడానికి తక్కువ ఖర్చుతో చిన్న క్యూరేటెడ్ డేటాసెట్‌పై చేసే శిక్షణ.
2. **ప్రశ్న: Large Language Models లో హాలూసినేషన్ (Hallucination) అంటే ఏమిటి? అది ఎందుకు వస్తుంది?**
   - **సమాధానం:** మోడల్ వాస్తవానికి లేని అబద్ధాలను అత్యంత నమ్మకంగా, అందమైన భాషలో నిజంలా చెప్పడాన్నే హాలూసినేషన్ అంటారు. LLM లు నిజాలను వెతికే గూగుల్ సెర్చ్ ఇంజిన్లు కావు; అవి కేవలం వ్యాకరణం ప్రకారం తర్వాతి పదాన్ని ఊహించే సంభావ్యతా ఇంజిన్లు కాబట్టి డేటా లేని చోట సొంతంగా కథలు అల్లేస్తాయి.
3. **ప్రశ్న: Top-P (Nucleus Sampling) కి మరియు Top-K కి మధ్య తేడా ఏమిటి?**
   - **సమాధానం:** **Top-K** అనేది ఎల్లప్పుడూ ఒక నిర్దిష్ట స్థిరమైన సంఖ్య ($K$) గల బెస్ట్ పదాలనే ఎంచుకుంటుంది. **Top-P** అనేది సంభావ్యతల మొత్తం $P$ (ఉదాహరణకి 0.95) వచ్చేంతవరకు మాత్రమే డైనమిక్‌గా పదాలను ఎంపిక చేస్తుంది; దీనివల్ల ఒక స్పష్టమైన సమాధానం ఉన్నప్పుడు తక్కువ పదాలను, సందిగ్ధంగా ఉన్నప్పుడు ఎక్కువ పదాలను పరిగణనలోకి తీసుకుంటుంది.
